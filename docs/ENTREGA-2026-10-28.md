## Qué es real y qué es demostración

**Real:**

- Todo el diseño, la maquetación responsive (escritorio, tableta y celular)
- La navegación entre portada, secciones y fichas
- El filtro por sección, el contador del carrito, el aviso flotante y el buscador
- La tipografía autoalojada (sin Google Fonts), HTTPS y el despliegue automático

**Demostración (todavía no conectado a base de datos):**

- Los 30 productos: nombres, marcas, precios y existencias son inventados pero realistas
- El carrito vive en memoria: si recargas la página se reinicia
- El mapa es una ilustración: no muestra un repartidor real
- Los formularios de cuenta y el checkout no existen aún

## Cómo correrlo en local (para desarrollo)

```bash
cd C:\Proyectos\distribuidora
npm run dev
# http://localhost:3000/tienda
```

Requiere Node 20 o superior. El proyecto ya trae las dependencias instaladas.

Para republicar el sitio estático después de cualquier cambio:

```bash
npm run dev                                  # en otra terminal
python3 scripts/tienda-static-export.py      # genera dist-pages/
# copiar dist-pages/ a la rama gh-pages y hacer push
```

## Decisiones técnicas tomadas

1. **Ruta `/tienda`**, no `/` — la raíz ya la ocupa el panel del POS. Cuando la
   tienda deba ser la portada, movemos el POS a `/pos` (es mover carpetas).
2. **CSS propio, aislado en `.t-root`** — el POS es oscuro y la tienda clara;
   comparten repositorio, no sistema visual.
3. **Paleta 60/30/10**: blanco cálido, verde profundo `#0e5134` y ámbar solo en
   etiquetas. Máximo tres tarjetas por fila, dos en celular.
4. **GitHub Pages sirve un snapshot estático** — el sitio real necesita Node.
   El snapshot se regenera con un script, no se edita a mano.

## Lo que necesitamos que definan

1. **Nombre y logo reales** de la distribuidora (ahora dice "Distribuidora").
2. **WhatsApp y correo verdaderos** (hoy hay un número de ejemplo).
3. **Catálogo real**: ¿cuántos productos, qué presentaciones y qué precios de
   mayoreo? Con eso se llena la base y se conectan las páginas a Prisma.
4. **Zonas de entrega y pedido mínimo** (hoy dice CDMX, zona metropolitana y $500).
5. **¿Se cobra en línea o solo transferencia/contra entrega?** El pago con
   tarjeta son 2 a 3 semanas extra de trabajo.
6. **Fotos de producto**: idealmente fondo blanco, misma proporción y mismo ángulo.

## Notas de la sesión (para quien retome el código)

- **Next 16:** `params` es una `Promise`; hay que desenvolverlo con
  `await params` o la ruta responde 404.
- **CSS:** el reset `button { border: 0 }` tiene más especificidad que
  `.t-btn--ghost`; los componentes con borde usan `.t-root .t-btn--ghost`.
- **El exportador** descubre rutas solo (lee los `href` del HTML renderizado) y
  escribe una hoja compartida en `assets/tienda.css`.
- **Rama `gh-pages`:** solo el sitio estático, nunca el código fuente.
